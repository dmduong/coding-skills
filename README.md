# coding-skills

A collection of GitHub Copilot skills and prompts for Node.js backend development, with a focus on NestJS APIs, MySQL, and TypeORM.

## What this project provides

- **API documentation to code:** Turn an API wiki or specification into NestJS code. The workflow can generate DTOs, controllers, services, response objects, and exception mappings, either end to end or one layer at a time.
- **Conventional Commit messages:** Generate a commit message based on the staged changes in your repository.

## Getting started

Open this repository in VS Code with GitHub Copilot enabled. To generate API code, provide an API wiki or specification and invoke `/docs-to-code` for the full workflow, or request a specific layer such as a DTO, controller, service, or response object.

For details about the documentation-to-code workflow and supported requests, see the [docs-to-code guide](.github/skills/docs-to-code/README.md).
